## Description
AeroDiary is an offline travel diary for flyers. Log a flight, rate the flight, airports and food, and get next-trip suggestions from your own ratings.

## Planned features
**Must:** add/view/edit/delete journeys, airport search with auto distance, ratings and meals, photo attach (camera/gallery), search/filter/sort
**Should:** settings, airport reviews, stats, ticket price and cost per km
**Could:** next-trip suggestions, wishlist, compare airports, badges, login

## Tech stack
Flutter, Dart, SQLite (sqflite), image_picker

## Setup
1. Install Flutter and Android Studio
2. git clone https://github.com/sumamaqazi098/aerodiary.git
3. flutter pub get
4. flutter run
